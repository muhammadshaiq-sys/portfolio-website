📖 Project Overview

The Bilingual AI Agent is designed specifically for Pakistan's 50M+ WhatsApp users, supporting natural language queries in Urdu, English, and Urduish (mixed language). This agent understands and responds in the user's preferred language, making AI accessible to non-English speakers across Pakistan's diverse population.

"یہ AI ایجنٹ اردو اور انگریزی دونوں زبانوں میں سوالات کو سمجھتا اور جواب دیتا ہے۔"

⚡ Key Features

  • Full Urdu and English language support
  • WhatsApp-first deployment (no app needed)
  • Voice message support (coming soon)
  • Culturally aware responses for Pakistani context
  • Works with Roman Urdu (Urdu written in English script)
  • Fine-tuned on Pakistani Urdu datasets

🔧 Technical Architecture

The agent uses a fine-tuned Llama 3.3 70B model with additional Urdu language tokens, integrated with WhatsApp Business API for seamless messaging. The system includes a custom Urdu tokenizer and handles code-switching (Urduish) effectively. Responses maintain cultural sensitivity and use appropriate Islamic greetings when contextually relevant.

📊 Target Use Cases

  • Educational institutions - student queries in Urdu
  • Healthcare - patient information in native language
  • E-commerce - customer support in Urdu/English
  • Government services - citizen information portals
  • Banking - customer service in preferred language
